浮動小数点数 (float) 型

  • Floating Point Number
  • $\{0, 1\}$で実数の近似値を表す方法
  • 絶対値が大きいものから小さいものまで
  • 正負両方（符号付き）
  • 簡単のため8ビット □ □□□□ □□□ で解説

浮動小数点数 (float) 型

$f = (-1)^{s} \times 2^{e-7} \times (1+t)$
$s$: 符号部，$e$: 指数部，$t$: 仮数部
$s$: 符号部 □ □□□□ □□□ 0: 正, 1: 負
$e$: 指数部 □ □□□□ □□□
$2^{e-7}$（整数 $\tiny\boxed{2^{3}}\boxed{2^{2}}\boxed{2^{1}}\boxed{2^{0}}$）
例）□ 1111 □□□ $\small \Rightarrow e=15 $$\small \Rightarrow 2^{15-7}=2^{8}$
$t$: 仮数部 □ □□□□ □□□
$1+t$ （小数 $\tiny\boxed{2^{-1}}\boxed{2^{-2}}\boxed{2^{-3}}$）
例）□ □□□□ 100 $\Rightarrow t=\frac{1}{2}$$\Rightarrow 1+t = 1.5$

浮動小数点数の計算例 (1)

$f = (-1)^{s} \times 2^{e-7} \times (1+t)$

$0\, 0110\, 100$
$\Rightarrow (-1)^0 \times 2^{6-7} \times (1+0.5)$
$=2^{-1}\times 1.5$
$=0.75$

浮動小数点数の計算例 (2)

$f = (-1)^{s} \times 2^{e-7} \times (1+t)$

$1\, 0000\, 110$
$\Rightarrow (-1)^1 \times 2^{0-7} \times (1+0.75)$
$=-2^{-7}\times 1.75$
$=-0.013671875$

浮動小数点数の計算例 (3)

$f = (-1)^{s} \times 2^{e-7} \times (1+t)$

$0\, 1111\, 111$
$\Rightarrow (-1)^{0} \times 2^{15-7} \times (1+0.875)$
$=480$

変数 (variables)

値をメモリ（主記憶装置）に保存（格納）しておき，名札をつけて再利用できるようにする仕組み

変数の利点

  • 再利用可能
  • 変数を変更 → 複数ヶ所を一括変更
  • 計算（演算）可能

変数の作成

  1. データ型 (int, float, char, ...)の宣言
  2. 変数の生成
  3. 値の代入
	
	  int x; // 1. データ型, 2. 命名 （変数の宣言）
	  x = 12; // 3. 値の代入
	
      
	
	  int x = 12; // 1. 2. 3.
注意）1. 2. の変数の宣言はソースコード中で1度しか宣言できません．
	
	  int x = 12;
	  int x;
	
	Duplicate local variable x
	
コンソールにエラーメッセージ

型の変換

	
	  int x = 12.2;
	
	cannot convert from float to int
変数 x はint型としてメモリ上に用意されているので，小数の値を記憶できない．
	
	  float x = 12;
自動的に浮動小数点数 12.0 に変換され，エラーメッセージは出力されない．

三角函数（数学II）

原点$O$を中心として半径$r$の円$c$を考える．

$x$軸と$c$との交点を$A$，円上の任意の点を$P$とし， 角度 $t := \angle AOP$とする．

このとき，以下のように三角函数が定義される

$\cos t := \frac{x}{r}$

$\sin t := \frac{y}{r}$

円の媒介変数表示（数学III）

$O$ を中心とする半径 $r$ の円を $c$とする．

$c$ 上の点 $P(x, y)$ は
三角函数で表すことができる．

$x= r \cos t$

$y= r \sin t$

点$C(a, b)$を中心とする半径$r$の円を$c$とする．

$c$ 上の点$P(x, y)$は三角函数で表すことができる．

$x= a + r \cos t$

$y= b + r \sin t$

三角函数の利用

	
size(300, 300);
int n = 5;
int r = 80;
int a = width/2;
int b = height/2;
float s = TWO_PI/n
for (int i=0; i < n; i++) {
  float x = a + r * cos(i*s);
  float y = b + r * sin(i*s);
  ellipse(x, y, 20, 20);
}
