コンピュータの画面

ウィンドウの座標

方眼紙と似ている

  • 画素 (pixel) が並んだもの
  • 画素の位置を$(x, y)$座標で表す
  • 左上隅が原点$(0, 0)$
  • $x$座標は右向きに正
  • $y$座標は下向きに正
  • 左図は20x10ピクセルを20倍に拡大した

ウィンドウを開く

03_01 ウィンドウを描く

		
size(400, 200);

教科書は幅800高さ600

関数 size()
  • 2つのパラメータ
  • 幅 (width) 400
  • 高 (height) 200
  • パラメータを引数（ひきすう）とも呼ぶ．
  • パラメータや命令を自分で変更して確認してみることが重要

03 02 点を描く

		
                  size(400, 100);
                  point(200, 50);
関数point()
  • 2つのパラメータ
  • 点の座標$(x, y)$
  • 左図はクリックすると直径4の円を描くように改変

基本的な図形

直線 (line) 線分 (segment)

		
line(x1, y1, x2, y2);

長方形 (rectangle, 矩形)

		
rect(x, y, w, h);

基本的な図形

三角形 (triangle)

		
triangle(x1, y1, x2, y2, x3, y3);

楕円 (ellipse)

		
ellipse(x, y, w, h);

基本的な図形

四角形 (quadrilateral)

		
quad(x1, y1, x2, y2, x3, y3, x4, y4);

円弧(arc)

		
arc(x, y, w, h, start, stop);

弧度法 (radian)

半径1の円の円弧の長さを用いて角度を測定

角度の固有名
弧度法の値で指定

360分法 (arc degree)

円周を360等分して角度を測定

関数radians()
360分法の値で指定

描画の順序

03 09 描画の順序


size(480, 120);
ellipse(140, 0, 190, 190);
// 長方形は円の上
rect(160, 30, 260, 20);

03 10 順序を逆にする


size(480, 120);
rect(160, 30, 260, 20);
// 円は長方形の上
ellipse(140, 0, 190, 190);

コメント

  • $//$はコメントの目印
  • 書かれた文はコンピュータに無視される
  • 人間のためのメモ書き用
  • 複数の選択肢を試したいときにも利用
  • $/*$と$*/$で複数行を挟む方法もあります

size(200, 200);
/*
fill(185, 62, 62);
fill(124, 24, 24);
*/
ellipse(100, 100, 80, 80);

複数の選択肢を試したいとき


size(200, 200);
//fill(185, 62, 62);
fill(124, 24, 24);
ellipse(100, 100, 80, 80);

              

size(200, 200);
fill(185, 62, 62);
//fill(124, 24, 24);
ellipse(100, 100, 80, 80);

まとめ

  • コンピュータの画面は画素(pixel)が並んだもの
  • 左上が原点$(0, 0)$
  • $x$軸は右向きに正，$y$軸は下向きに正
  • 座標$(x, y)$を指定して図形を描画
  • 角度は弧度法で時計回りに指定
  • 関数radians()で360分法に対応
  • 先頭から順に命令が実行される
  • $//$から始まる行は実行時に無視される
  • コメント文と呼ばれる（教科書P34）
