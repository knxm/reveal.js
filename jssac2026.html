コンテナエンジン

  • 2013年3月, Docker社からDocker公開
  • 2018年3月，RedHat社からPodman公開
  • 主にサーバ用途で普及
  • 現在，レジストリサービスとしてdocker.io, quay.io, ghcr.ioなどが知られている．

様々なコンテナエンジン

  • Docker (Docker Inc.)
  • Podman (Red Hat)
  • Container (Apple)
  • Apptainer (Singularity, LF Projects)

OCI (The Open Container Initiative)

コンテナの業界標準を定めるための団体

  • Open Container Initiative Runtime Specification
  • OCI Image Format Specification

コンテナの利点

一貫性
開発環境のパッケージ化，アーカイブ化．

分離とセキュリティ
プロセスの隔離
可搬性，配布性
コンテナ単位での配布，レジストリサービスの利用
マイクロサービスによるスケーラビリティ
ソフトウェア単体での提供

Containerfile

	    
FROM debian:trixie-slim

ENV DEBIAN_FRONTEND=noninteractive
ENV LANG=C.UTF-8

USER root

# Fundamental tools
RUN apt-get update && apt-get install -y --no-install-recommends \
    ca-certificates \
    gnupg \
    wget \
    bash \
    locales

RUN wget -qO- https://www.math.kobe-u.ac.jp/deb2/fe-deb2-archive-keyring.gpg \
    | gpg --dearmor -o /usr/share/keyrings/mathkobe.gpg

# Risa/Asir repository in Kobe University
RUN echo "deb [trusted=yes] http://www.math.kobe-u.ac.jp/deb2/ unstable/" \
    > /etc/apt/sources.list.d/asir.list
RUN touch /tmp/i-agree-with-asir-license

# Install OpenXM
RUN apt-get update && apt-get install -y --no-install-recommends \
    vim-tiny \
    openxm \
 && apt-get clean \
 && rm -rf /var/lib/apt/lists/*

# Making user
RUN useradd -m -s /bin/bash user
USER user
WORKDIR /home/user
RUN mkdir -p /home/user/work

CMD ["bash"]

Makefile

	    
ENGINE     ?= podman
REGISTRY   ?= ghcr.io
OWNER      ?= knxm
APP_NAME   ?= openxm
TAG        ?= latest
HOSTNAME   ?= mathlibre
HOST_WORKDIR := $(CURDIR)/work
WORKDIR    := /work

IMAGE ?= $(REGISTRY)/$(OWNER)/$(APP_NAME):$(TAG)

UNAME_S := $(shell uname -s)
UNAME_R := $(shell uname -r)

UID := $(shell id -u)
GID := $(shell id -g)
PWD := $(shell pwd)

PLATFORM ?= linux/amd64

# ------------------------
# Initialize X11
# ------------------------
X11_DISPLAY :=
XVOL :=
XAUTH :=
XAUTHVOL :=

# ------------------------
# Linux / WSLg
# ------------------------
ifeq ($(UNAME_S),Linux)
	# WSLg 
	ifneq (,$(findstring microsoft,$(UNAME_R)))
		X11_DISPLAY := :0
		XVOL := -v /tmp/.X11-unix:/tmp/.X11-unix:rw
	else
		# Native Linux
		X11_DISPLAY := :0
		XAUTH := -e XAUTHORITY=$(XAUTHORITY)
		XVOL := -v /tmp/.X11-unix:/tmp/.X11-unix:rw
		XAUTHVOL := -v $(XAUTHORITY):$(XAUTHORITY):ro
	endif
endif

# ------------------------
# macOS + XQuartz
# ------------------------
ifeq ($(UNAME_S),Darwin)
	X11_DISPLAY := host.docker.internal:0
	XVOL :=
endif

# ------------------------
# run options
# ------------------------
RUN_OPTS = \
	-it --rm \
	--name $(APP_NAME) \
	--hostname $(HOSTNAME) \
	--userns=keep-id \
	--platform=$(PLATFORM) \
	-u $(UID):$(GID) \
	-e DISPLAY=$(X11_DISPLAY) \
	$(XAUTH) \
	$(XVOL) \
	$(XAUTHVOL) \
	-v "$(HOST_WORKDIR):$(WORKDIR)" \
	-w $(WORKDIR)

# ------------------------
# targets
# ------------------------
.PHONY: run shell pull clean size build push

run: 
	$(ENGINE) run $(RUN_OPTS) $(IMAGE) openxm asir

shell: 
	$(ENGINE) run $(RUN_OPTS) $(IMAGE) bash

pull:
	$(ENGINE) pull --platform=$(PLATFORM) $(IMAGE)

clean:
	$(ENGINE) rmi $(IMAGE)

size:
	$(ENGINE) image inspect $(IMAGE) | jq '.[0].Size'

# for maintainer
build:
	$(ENGINE) build --platform=$(PLATFORM) -t $(IMAGE) .

push:
	$(ENGINE) push $(IMAGE)

利用方法

mathlibre-c 内でmakeを実行することで利用可能

  • コンテナをダウンロード後にRisa/Asirが起動
  • コンテナのシェルを使用したい場合はmake shellを入力
  • 解凍後のコンテナサイズは約860MB
  • mathlibre-c/workは作業用のディレクトリとしてマウント
  • 好みのテキストエディタでwork内にスクリプトを作成
  • サンプルファイル test_fctr.rr, test_c7.rr
  • 例えばAsir shellでload(test_c7.rr);
  • コンテナ内でroot（管理者）になることはできません。
  • 追加したい場合にはContainerfileを編集して make buildを実行

まとめ

  • Risa/Asir(OpenXM)のためのコンテナ
  • WSL2もしくはHomebrewの利用
  • 教育利用への対応
